# Apartment Booking & Management System

A backend application designed for listing, discovering, and booking short-term and long-term apartments.

---

## Key Features

### For Guests (Tenants)
* **Advanced Search & Filtering:** Filter properties by location, check-in/check-out dates, price range, guest capacity.
* **Real-Time Availability:** Instant conflict checking to prevent double bookings.
* **Secure Checkout:** Integrated payment processing (Stripe) with automated PDF invoice generation.
* **Booking Management:** View upcoming stays, modify reservation dates, request cancellations, and leave verified reviews.

### For Hosts (Apartment Managers)
* **Property CRUD & Media Management:** Create listings, upload high-resolution image galleries, and set custom house rules.
* **Dynamic Pricing & Calendar Control:** Block off maintenance dates and set seasonal or weekend pricing tiers.
* **Reservation Pipeline:** Approve or decline booking requests (or enable Instant Book) and track guest check-ins.
* **Analytics & Payouts:** Visual dashboard tracking occupancy rates, monthly revenue, and payout history.

### For Administrators
* **User & Listing Moderation:** Verify host identities, approve new listings, and resolve disputes.
* **Platform Metrics:** Monitor gross merchandise value (GMV), active users, and system health.
